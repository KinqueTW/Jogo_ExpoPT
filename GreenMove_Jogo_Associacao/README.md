# GreenMove — Jogo de Associação Ambiental

Jogo simples feito com Python + Flask, HTML, CSS e JavaScript.

## Como executar

1. Instale o Flask:
   `pip install flask`
2. Entre na pasta do projeto.
3. Execute:
   `python app.py`
4. Abra no navegador o endereço mostrado pelo Flask.

O jogo aceita arrastar com mouse e também com toque em celular/tablet.
